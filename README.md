
# 📝 To-Do List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript as part of the **Codveda Web Development Internship – Level 2, Task 2**.

The app helps users organize their daily activities by adding, editing, deleting, and completing tasks. It uses browser localStorage to save tasks even after the page is refreshed.

## ✨ Features

- ➕ Add new tasks
- ✏️ Edit existing tasks
- 🗑️ Delete tasks
- ✅ Mark tasks as completed
- 💾 Save tasks using localStorage
- 📱 Responsive design for mobile and desktop
- 🔄 Automatically display saved tasks after refreshing

## 🛠️ Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive layout
- **JavaScript** – Task management and app functionality
- **LocalStorage** – Saving tasks in the browser

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks!
